# Assist Path

Assist 시리즈(Reel · Mine · Farm · Lumber · Travel …)의 길찾기 모듈이에요. Made by seolwoni

- Baritone의 A* 길찾기와 이동 비용 계산을 가져와 다듬었어요 (걷기, 오르기, 내려가기, 대각선, 떨어지기, 아래로 파기, 기둥 쌓기, 파쿠르).
- 경로 계획만 하고, 실제 움직임은 Assist Core가 사람처럼 해요.
- 원칙: 지형 정보는 길 계산에만 쓰고, 벽 너머의 광석이나 상자를 찾는 데는 쓰지 않아요.

라이선스: **LGPL-3.0** (Baritone 기반). 자세한 출처와 바꾼 점은 `NOTICE.md`를 보세요.

## 자동 테스트 (0.1.0)
게임 안에서 6가지 지형을 만들어 길을 찾게 해요: 평지, 벽 돌아가기(부수지 않음), 4칸 언덕 오르기, 용암 웅덩이 피하기, 닫힌 방 뚫고 나가기(2블록), 3칸 아래로 내려가기 — 모두 통과.
